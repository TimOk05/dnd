Веб-приложение для генерации персонажей и противников для настольной ролевой игры Dungeons & Dragons 5e с интеграцией AI для создания описаний и тактики.

## 🚀 Основные возможности

### Генерация персонажей
- **22 расы**: Человек, Эльф, Дварф, Полурослик, Орк, Тифлинг, Драконорожденный, Гном, Полуэльф, Полуорк, Табакси, Ааракокра, Гоблин, Кенку, Ящеролюд, Тритон, Юань-ти, Голиаф, Фирболг, Багбир, Хобгоблин, Кобольд
- **13 классов**: Воин, Волшебник, Плут, Жрец, Следопыт, Варвар, Бард, Друид, Монах, Паладин, Чародей, Колдун, Изобретатель
- **AI-описания**: Автоматическое создание описаний и предысторий персонажей через DeepSeek API
- **Fallback система**: При недоступности AI используются качественные предустановленные описания
- **Полные характеристики**: Хиты, КД, скорость, инициатива, попадание, урон, владения, заклинания, снаряжение
- **Случайные параметры**: Мировоззрение, пол, профессия из JSON базы данных
- **Система имен**: Автоматический выбор имен по расе и полу из расширенной базы данных
- **Боевые характеристики**: Отдельные поля для попадания и урона с указанием оружия

### Генерация противников
- **Расширенная база данных**: 19+ монстров разных уровней сложности (CR 1/8 - 13)
- **AI-описания**: Тактика и поведение противников
- **Боевые характеристики**: Полная информация для боя
- **Фильтрация**: По уровню угрозы, типу, окружению

### Система боя
- **Управление инициативой**: Автоматическая сортировка участников по инициативе
- **Управление ходами**: Переход между ходами с подсчетом раундов
- **Управление хитами**: Добавление/удаление урона и лечения
- **Статусы участников**: Активен, без сознания, мертв
- **Бросок инициативы**: Встроенный генератор с бонусами
- **Интеграция с заметками**: Добавление персонажей и противников из заметок

### AI Помощник
- **Контекст D&D**: Специализированный помощник для мастеров D&D 5e
- **Поддержка PDF**: Загрузка ваншотов для создания приключений
- **История чата**: Сохранение контекста разговора
- **Улучшенный интерфейс**: Адаптивный дизайн для мобильных устройств

### Дополнительные функции
- **Сохранение в заметки**: Сохранение персонажей и противников в сессии
- **Система инициативы**: Добавление персонажей из заметок в инициативу
- **Мобильная версия**: Адаптивный дизайн для всех устройств
- **PWA поддержка**: Можно установить как приложение
- **Три темы оформления**: Светлая, средняя (коричневая), темная

## 🔧 Техническая архитектура

- **JavaScript функции**:
  - `formatCharacterFromApi()` - форматирование персонажей
  - `formatEnemiesFromApi()` - форматирование противников
  - `saveCharacterToNotes()` - сохранение персонажей
  - `saveEnemyToNotes()` - сохранение противников
  - `addFromNotes()` - добавление из заметок в инициативу
  - `sendAIMessage()` - отправка сообщений в AI чат
- **AJAX запросы**: Для взаимодействия с API
- **Адаптивный дизайн**: CSS Grid и Flexbox

## 🐛 Известные проблемы и решения

### Проблемы с cURL
- **Симптом**: "cURL недоступен" - AI описания не генерируются
- **Решение**: Установить расширение cURL для PHP или использовать fallback описания
- **Текущее состояние**: При отсутствии cURL используются качественные fallback описания

### Проблемы с API
- **Симптом**: Ошибки HTTP запросов
- **Решение**: Fallback на локальные данные в `fallback-data.php`

### Проблемы с валидацией
- **Симптом**: "Ошибка генерации характеристик"
- **Решение**: Диапазон характеристик 3-20, проверка в `generate-characters.php`

### Проблемы с PDF
- **Симптом**: PDF файлы не обрабатываются
- **Решение**: В текущей версии используется заглушка, для полной поддержки нужна библиотека pdfparser

## 🔄 Процесс разработки

### Добавление новой расы
1. Добавить в `$valid_races` в `generate-characters.php`
2. Добавить данные в `getRaceData()` в `generate-characters.php`
3. Добавить имена в `getNamesByRace()` в `generate-characters.php`
4. Добавить в интерфейс в `index.php`

### Добавление нового класса
1. Добавить в `$valid_classes` в `generate-characters.php`
2. Добавить данные в `getClassData()` в `generate-characters.php`
3. Добавить в интерфейс в `index.php`

### Добавление нового монстра
1. Добавить в `getMonsters()` в `fallback-data.php`
2. Убедиться в корректности CR и типа
