## 🔧 Если что-то не работает

### 1. Проверьте права доступа
```bash
chmod 755 cache logs uploads
chmod 644 .env config.php
```

### 2. Проверьте логи
Смотрите файлы в папке `logs/`:
- `app.log` - общие ошибки
- `security.log` - проблемы безопасности
- `rate_limit.log` - превышения лимитов

### 3. Проверьте .env файл
Убедитесь, что файл `.env` существует и содержит:
```env
DEEPSEEK_API_KEY=sk-1e898ddba737411e948af435d767e893
APP_NAME="D&D Copilot"
DEBUG_MODE=false
```
