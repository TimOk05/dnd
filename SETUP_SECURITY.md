## 📋 **Инструкции по настройке**

### **Шаг 1: Настройка переменных окружения**

1. Скопируйте файл `env.example` в `.env`:
```bash
cp env.example .env
```

2. Отредактируйте `.env` файл, заменив значения на реальные:
```env
# API Keys
DEEPSEEK_API_KEY=sk-your-real-deepseek-api-key-here

# Application Settings
APP_NAME="D&D Copilot"
APP_VERSION="3.1"
DEBUG_MODE=false
ENVIRONMENT=production

# Security
JWT_SECRET=your-super-secret-jwt-key-here
SESSION_SECRET=your-session-secret-key-here
```

### **Шаг 2: Создание необходимых директорий**

```bash
mkdir -p cache/api
mkdir -p cache/rate_limits
mkdir -p logs
chmod 755 cache cache/api cache/rate_limits logs
```

### **Шаг 3: Настройка прав доступа**

```bash
# Защищаем конфигурационные файлы
chmod 600 .env
chmod 644 config.php

# Защищаем директории кэша и логов
chmod 755 cache logs
chmod 644 cache/.htaccess logs/.htaccess
```

### **Шаг 4: Проверка работоспособности**

## 🔧 **Настройка лимитов**

### **Rate Limiting настройки**

В файле `services/RateLimiter.php` можно изменить лимиты:

```php
private $limits = [
    'login' => ['requests' => 5, 'window' => 900],      // 5 попыток за 15 минут
    'api' => ['requests' => 100, 'window' => 3600],     // 100 запросов в час
    'ai' => ['requests' => 50, 'window' => 3600],       // 50 AI запросов в час
    'character' => ['requests' => 20, 'window' => 3600], // 20 персонажей в час
    'default' => ['requests' => 10, 'window' => 3600]   // 10 запросов в час по умолчанию
];
```

### **Кэширование настройки**

В файле `services/APICache.php` можно изменить TTL:

```php
public function __construct($cachePath = null, $defaultTTL = 3600) {
    // $defaultTTL = 3600; // 1 час по умолчанию
}
```

### **Статистика кэша**

Создайте файл для просмотра статистики кэша:

```php
<?php
require_once 'services/APICache.php';

$cache = new APICache();
$stats = $cache->getStats();

echo "Статистика кэша:\n";
echo "Всего файлов: " . $stats['total_files'] . "\n";
echo "Истекших файлов: " . $stats['expired_files'] . "\n";
echo "Валидных файлов: " . $stats['valid_files'] . "\n";
echo "Общий размер: " . number_format($stats['total_size'] / 1024, 2) . " KB\n";
```
